# 변경 요약

- 일정·일차 ID별 개인 메모와 작성·수정·삭제·자동 저장
- 장소 좌표를 따라 이동·확대되는 지도 마커와 포스트잇형 편집 창
- 같은 장소의 여러 일정은 마커만 묶고 본문은 별도 저장
- 계정별 화면 구분, 보호자·공개 안내판·인쇄·게시판 공유 제외
- 저장 실패 경고, 오프라인 첫 작성, 재열람과 다른 탭 동기화

## 검증

- 메모 데이터 검사 5개, 기존 게시판 서버 검사 16개 통과
- 실제 브라우저 9개 흐름: 저장·재열람·삭제, 지도 이동·확대, 일정 구분, 계정 전환·로그아웃·보호자 제외, 저장 실패·복구, 일차 전체·장소 없는 일정, 다른 탭 반영, 공개 안내판·인쇄 제외, 외부 요청에 본문 미포함
- 360/768/1280px, 200% 글씨, 키보드 초점과 모션 감소 확인
- TypeScript, 전체 빌드, 공개 안내판 개인정보 검사와 기존 오프라인 안내서 생성 통과

이 검토안의 자동 검사는 순수 데이터 규칙 5개만 실행합니다. 위 화면·빌드 결과는 보관된 원본 앱의 가상 계정 테스트 결과이며 실제 운영 앱 적용 완료를 뜻하지 않습니다.
