# 변경 사항과 남은 작업

## 학생 화면

- 메뉴에 `탐방 이야기`, 장소 안내에 `이 장소의 이야기` 진입점 추가
- 지역·장소·글 유형별 필터, 최신순 목록과 20개 단위 추가 조회
- 제목 100자, 본문 10,000자, 사진 최대 5장, 댓글 1,000자
- 본인 글의 제목·본문·분류 수정과 삭제, 본인 댓글 삭제
- 기기에 계정별 초안과 사진 초안 저장, 오프라인 텍스트 작성
- 서버 저장 성공 전에는 게시 완료로 표시하지 않고 초안 유지

## 교사 관리

- 게시글 숨김·복구, 댓글 삭제
- 숨긴 글의 학생 목록·직접 URL·댓글·사진 접근 차단
- 관리 변경의 감사 기록

## 서버와 데이터

- 독립 Node.js HTTP 서비스, SQLite 저장 구현, 저장 어댑터 인터페이스
- 기존 ZUDO `/api/trip/me`로 로그인 토큰·역할·만료 확인
- 서버가 정한 작성자와 역할만 사용하고, 다른 학생의 수정·삭제 거부
- 글·댓글·사진을 함께 저장하고, 글 삭제 시 댓글·사진도 함께 처리
- 수정 버전 충돌 감지, 응답 유실 후 재전송의 중복 게시 방지
- 사진 매직 바이트·크기·픽셀 수 검사, JPEG 재처리와 EXIF·GPS 제거
- 비공개 API·사진의 서비스 워커 캐시 제외, 요청 크기·빈도 제한
- 별도 HTTPS API 주소와 허용 출처 설정 지원
